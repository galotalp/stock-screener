How this page updates

The rankings and sentiment come from a Python pipeline (market-wide fundamentals via yfinance plus live web-sentiment research) that takes ~20–30 minutes to run — too heavy for a static web page to trigger on its own. To refresh, I run one command locally that re-screens the market, re-scores sentiment, rebuilds this page and pushes it live:

./update_lynch.sh

The Last updated date above always reflects the most recent run.
